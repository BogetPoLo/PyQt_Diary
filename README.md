# PyQt Diary

## Школьный дневник на Python с графическим интерфейсом на PyQt6.

Изначально проект был разработан как задание по программе Яндекс Лицея (один из трех проектов). Реализация настолько 
понравилась площадке(школа №1569), что дневник со временем начали использовать как временную замену МЭШ, 
когда сервис падал или становился недоступен. Так учебный проект вышел за рамки обычного задания и пригодился в реальной школьной жизни.

## Данные

Файл `school.db`, который лежит в репозитории, — это тестовая база с примерными данными. После загрузки проекта и 
добавления своего класса её стоит обновить под себя: заменить тестовые данные на актуальные и настроить состав класса. 
Перед изменением базы рекомендуется сохранить копию исходного файла.

## Структура проекта
Основные файлы лежат в корне репозитория:

`main.py`	Точка входа: создаёт приложение Qt, настраивает общий стиль и открывает главное окно.

`Main_Win.py`	Главное окно и основной интерфейс дневника.

`Control_Diary.py`	Логика работы с дневником и связь между действиями пользователя и интерфейсом.

`Data_File.py`	Работа с данными, которые используются приложением.

`Contral_Add_Class.py`	Логика добавления данных, в том числе связанных с классом.

`Contol_help.py`	Вспомогательные функции и действия, связанные с помощью.

`Window_Dialog.py`	Диалоговые окна и сообщения пользователю.

`school.db`	Локальная база данных SQLite.

`requirements.txt`	Список Python-зависимостей проекта.

`main.exe`	Готовая сборка для Windows.

`.gitignore`	Файлы и каталоги, которые Git не должен отслеживать.
